Задание

$$1 + 2 + \dots + n = \frac{n(n+1)}{2}$$

Доказательство (методом математической индукции)

$$ \textbf{База индукции: Для} ( n = 1 ): [ 1 = \frac{1(1+1)}{2} = 1. ] \textbf{Предположение индукции: Пусть для} ( n = k ) \textbf{верно}: [ 1 + 2 + \dots + k = \frac{k(k+1)}{2}. ] \textbf{Шаг индукции: Докажем для} ( n = k + 1 ): [ 1 + 2 + \dots + k + (k+1) = \frac{k(k+1)}{2} + (k+1) = \frac{(k+1)(k + 2)}{2}. ] Полученное выражение совпадает с формулой при ( n = k + 1 ). $$
