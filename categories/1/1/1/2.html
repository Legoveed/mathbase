Задание

\[\textbf{Доказать методом математической индукции: }1^{2}+2^{2}+\dots+n^{2}=\frac{n(n+1)(2n+1)}{6}\]

Доказательство

\[\textbf{База } n=1: \space \frac{1(1+1)(2\dot 1+1}{6}=1\] \[\textbf{Предположение } n=k: \space 1^{2}+2^{2}+\dots+k^{2}=\frac{k(k+1)(2k+1)}{6}\] \[\textbf{Шаг } n=k+1: \space 1^{2}+2^{2}+\dots+k^{2}+(k+1)^{2}=\frac{k(k+1)(2k+1)}{6}+(k+1)^2=\frac{(k+1)(2k^2+7k+6)}{6}=\frac{(k+1)(k+2)(2k+3)}{6}\textbf{, что совпадает с подстановкой в исходную формулу значения }k+1 \space Q.E.D.\]
