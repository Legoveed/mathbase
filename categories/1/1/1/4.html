Задание

\[\textbf{Доказать методом математической индукции: }1+2+2^{2}+\dots+2^{n-1}=2^{n}-1\]

Доказательство

\[\textbf{База } n=1: \space 1=2^{1}-1=2\] \[\textbf{Предположение } n=k: \space 1+2+2^{2}+\dots+2^{k-1}=2^{k}-1\] \[\textbf{Шаг } n=k+1: \space 2^{k}-1+2^{k}=2\cdot 2^{k}-1 = 2^{k+1}-1 \textbf{, что совпадает с подстановкой в свёртку исходной формулы значения }k+1 \space Q.E.D.\]
