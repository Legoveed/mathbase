Задание

\[\textbf{Доказать методом математической индукции: }1^{3}+2^{3}+\dots+n^{3}=(1+2+\dots +n)^{2}\]

Доказательство

\[\textbf{База } n=1: \space 1^{3}=1^{2}\] \[\textbf{Предположение } n=k: \space 1^{3}+2^{3}+\dots+k^{3}=(1+2 + \dots + k)^{2} \href{1.html}{=\left(\frac{k(k+1)}{2} \right)^{2}}\] \[\textbf{Шаг } n=k+1: \space \left(\frac{k(k+1)}{2} \right)^{2} + (k+1)^{3} = \frac{(k+1)^{2}(k^{2}+4k+4)}{4} = \left(\frac{(k+1)(k+2)}{2} \right)^{2} \textbf{, что совпадает с подстановкой в свёртку исходной формулы значения }k+1 \space Q.E.D.\]
